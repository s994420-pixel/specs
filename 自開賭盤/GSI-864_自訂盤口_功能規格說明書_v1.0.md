## 1. 系統概述

### 1.1 功能目的

提升平台會員留存率與活躍度。站長可在後台自由建立事件競猜盤口（預測型玩法），會員可在前台瀏覽事件、投注、查看結果與個人注單。

**第一版採動態賠率莊家盤模型**：平台為莊家，承擔賠付風險；賠率依各選項下注比例即時動態調整，並透過抽水比例控制風險。

### 1.2 角色表

| 角色 | 權限範圍 |
|------|---------|
| 站長 / 代理（後台） | 建立、編輯、停用盤口；輸入結算結果；管理分類、匯率 |
| 第二組確認帳號 | 任意後台帳號（不得與帳號 A 相同），輸入確認結果 |
| 前台會員 | 瀏覽盤口、投注、查看注單與排行榜 |

### 1.3 系統架構總覽

| 模組 | 位置 | 說明 |
|------|------|------|
| 自訂盤口列表 | 後台 | 建立與管理盤口 |
| 盤口審核 | 後台 | 封盤後輸入結果、雙確認結算 |
| 盤口紀錄 | 後台 | 已結算或取消的歷史盤口 |
| 注單紀錄 | 後台 | 所有會員下注明細 |
| 詳細設定 | 後台 | 分類管理、匯率設定 |
| 盤口列表頁 | 前台 | 會員瀏覽與投注 |
| 排行榜 | 前台 | 盈利與交易量排名 |
| 我的注單 | 前台 | 個人下注紀錄與統計 |

## 2. 呈現模式定義（題型）

站長建立盤口時選擇「會員端呈現模式」，決定前台卡片呈現方式與選項邏輯。

| 模式 | 說明 | 選項數量 | 典型用途 |
|------|------|---------|---------|
| **單題雙選項（是/否）** | 固定「是」「否」兩選項 | 2 | 預測事件是否發生 |
| **多選一** | 自訂 N 個選項，會員選 1 | 3–N | 預測結果落在哪個選項 |
| **主選項判定** | 有一「主選項」，其餘為競爭選項 | 2–N | 猜主角/主隊是否勝出 |
| **對戰** | 兩方陣營對決 | 2 | 主客隊、A 對 B |

> 💡 AI 快速建盤固定使用「單題雙選項（是/否）」，站長建立後可手動改題型。

## 3. 賠率計算機制

### 3.1 動態賠率公式

```
選項賠率 = 總下注池 ÷ 該選項下注池 × (1 − 抽水率)
```

**舉例**（抽水 5%）：

| | 是 | 否 |
|--|----|----|
| 下注池 | 6,000 | 4,000 |
| 總池 | 10,000 | 10,000 |
| 動態賠率 | 10,000 ÷ 6,000 × 0.95 = **1.58** | 10,000 ÷ 4,000 × 0.95 = **2.38** |

- 賠率**即時動態調整**，每次有新下注即重算並推送前台
- 初始賠率（無人下注時）由系統自動計算，站長可手動覆蓋

### 3.2 多幣別換算規則

- 站長於「詳細設定 → 匯率設定」指定**全站基準幣別**（所有盤口共用）
- 會員以各自幣別下注；各幣別下注額**於結算時**換算為基準幣，再進行賠率計算與派彩
- ⚠️ 匯率快照時間點：**封盤當下**（非下注當下），結算時套用快照匯率

### 3.3 站長封盤後手動調整賠率

- 封盤後、輸入結果前，站長可在盤口審核頁手動調整各選項賠率
- 手動調整為**覆蓋值**，後續不再動態變動

- 排序維度：下注人數 / 交易量（基準幣別）
- 篩選：幣別、盤口分類

- 依幣別顯示本週最高贏利會員
- 帳號加密：前 3 碼 + `***` + 後 3 碼

### 4.3 新增 / 編輯盤口

分兩個 Step，Step 1 基本資料與賠率，Step 2 風控設定。

#### Step 1 — 基本資料 & 賠率設定

| 欄位 | 類型 | 必填 | 說明 / 限制 |
|------|------|------|------------|
| 開盤時間 | datetime | ✓ | 到達時系統自動上架 |
| 封盤時間 | datetime | ✓ | 到達時系統自動封盤；需晚於開盤時間 |
| 盤口分類 | Select | ✓ | 來自站長自訂分類清單 |
| 錢包類型 | Select | ✓ | 一般 / 贈金 / 撲滿；**建立後不可修改**（原因：變更會造成歷史注單錢包對帳錯誤） |
| 盤口名稱 | 多語系文字 | ✓ | 依站點開放語系填寫；列表顯示站點預設語系 |
| 題目 | 多語系文字 | ✓ | 前台顯示的競猜問題 |
| 廣宣圖 | 多語系圖片 | — | 可選；依語系上傳不同圖片 |
| 抽水比例 | 數值 % | ✓ | 影響動態賠率計算 |
| 會員端呈現模式 | Select | ✓ | 單題雙選項 / 多選一 / 主選項判定 / 對戰 |
| 投注選項名稱 | 多語系文字 × N | ✓ | 依題型決定選項數量 |
| 初始賠率 | 數值 | — | 系統自動計算；站長可手動覆蓋 |
| 基準幣別 | Select | ✓ | 全站共用設定，此處唯讀顯示（於詳細設定維護） |
| 最低下注額 | 多幣別數值 | ✓ | 各幣別分別設定；填 0 = 不設限 |
| 最高下注額 | 多幣別數值 | ✓ | 各幣別分別設定；填 0 = 不設限 |
| 各幣別換算預覽 | 唯讀顯示 | — | 依當前匯率即時換算顯示 |
| 啟用二次判定期 | Toggle / 勾選 | — | 預設關閉；開啟後若第一輪結果不一致，進入 2 小時二次判定 |

> 💡 onblur 空白的數值欄位自動補 0

#### Step 2 — 投注風控設定

| 欄位 | 類型 | 必填 | 說明 |
|------|------|------|------|
| 阻擋會員標籤 | 多選 Tag | — | 帶有指定標籤的會員無法投注 |
| 黑名單帳號阻擋 | 多行輸入 | — | 指定帳號阻擋 |
| 阻擋指定 IP | 多行 CIDR 輸入 | — | 支援 IP / CIDR |
| 同 IP 重複投注上限 | 數值 | — | 填 0 = 不設限；超過次數後阻擋該 IP 繼續下注 |

| 欄位 | 說明 |
|------|------|

| 基準幣別 | — |

#### 匯率設定

| 欄位 | 說明 |
|------|------|

### 4.8 AI 建立盤口事件（快速入口）

#### 入口位置

後台右下角封盤通知視窗內的「用 AI 快速建立新盤口事件」按鈕

#### 操作流程

1. 站長選擇題材分類（全部 / 指定分類）
2. 點擊「生成建議盤口」按鈕
3. AI 生成 4 個事件建議卡片（含題目、分類、建議抽水比例）
4. 站長點擊任一卡片 → 自動開啟新增盤口 Step 1，預填：
   - 題目（zh-tw）
   - 開/封盤時間（預設：下週一開盤 / 下週五 23:59 封盤）
   - 分類
   - 抽水比例
   - 呈現模式固定為「單題雙選項（是/否）」
5. 站長確認後可自行修改任何欄位，再進行下一步

#### AI 建盤標識

建立完成的 AI 盤口，列表標題左側顯示「✦ AI」標籤

#### 安全防護

- System Prompt 防護咒語（防 Prompt Injection）
- 前端輸入注入過濾，上限 500 字

## 5. 結算流程（雙帳號確認機制）

### 5.1 流程總覽

```
封盤
  │
  ▼
① 等待第一組後台帳號（A）輸入獲勝選項
  │
  ▼
② 等待第二組後台帳號（B）輸入獲勝選項
  │  ⚠️ A、B 不得為同一帳號（任意後台帳號均可）
  │  ⚠️ 若超時未完成 → 自動取消盤口並全額退款
  │
  ▼
③ 系統比對 A、B 結果
  ├── 一致 → 以輸入結果前的賠率快照結算 → 自動派彩（一般/贈金/撲滿錢包）→ 結束
  └── 不一致
        ├── 未啟用二次判定 → 取消盤口，全額退款
        └── 已啟用二次判定
              │
              ▼
        ④ 進入二次判定期（2 小時，僅一次機會）
              │  等待 A 重新輸入 + B 重新輸入
              │  超時未完成 → 自動取消並全額退款
              ▼
        ⑤ 再次比對結果
              ├── 一致 → 以輸入結果前的賠率快照結算 → 自動派彩 → 結束
              └── 不一致 → 取消盤口，全額退款
```

### 5.2 規則補充

- 逾時取消：從**封盤**起計算，逾時時間視站長設定（目前以流程圖標示為主，具體時限請確認）
- 退款對象：該盤口所有已下注會員，退回原下注金額至原錢包
- 二次判定期：僅有一次機會，2 小時，再不一致即直接取消
- 結算賠率：系統以**輸入結果前的各選項賠率**作為快照進行結算（即封盤後站長手動調整的最終值；若未手動調整，則為封盤當下的動態賠率）

## 9. 注意事項與系統限制

- 【錢包類型】建立後不可修改，原因：變更會造成歷史注單錢包對帳錯誤
- 【基準幣別】全站自訂盤口共用，修改後立即生效，不影響已結算事件
- 【匯率快照】鎖定時間點為封盤當下，非下注當下；結算使用快照匯率
- 【注單賠率】下注成功後鎖定，不隨後續動態賠率變動
- 【二次判定期】僅有一次機會，2 小時；逾時或仍不一致直接取消並退款
- 【雙帳號限制】帳號 A 與帳號 B 不得為同一帳號，可為任意後台帳號
- 【AI 建盤題型】固定為「單題雙選項（是/否）」，站長確認後可改
- 【AI 安全防護】System Prompt 防護 + 前端注入過濾，輸入上限 500 字
- 【分類刪除保護】有進行中盤口使用的分類不可刪除
- 【帳號加密】前台排行榜帳號顯示格式：前 3 碼 + `***` + 後 3 碼
- 【本次不包含】站內信通知功能（另行安排）
